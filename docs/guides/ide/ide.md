# IBM i Developer Integrated Development Environment for IBM i Modernization Engine for Lifecycle Integration
![IBM i Modernization Engine for Lifecycle Integration IDE](../../images/guides/MerlinIDELight.png)   


IBM i Developer Integrated Development Environment (IDE) for IBM i Modernization Engine for Lifecycle Integration is a development environment that provides an in-browser IDE that you can use to develop IBM i applications from any machine. It provides a single-click developer workspace and eliminates local environment configuration.

Core capabilities
- Developer environment for teams
- One-click workspaces for IBM i platform
- Enterprise readiness and built-in security
- Modern editing experience for IBM i languages (RPG, SQL, and more)
- Interaction with IBM i objects and IFS files
- Support for project-based developer builds

For information on using ARCAD tools, see [How to use ARCAD integration with IBM i Modernization Engine for Lifecycle Integration](https://supportcontent.ibm.com/support/pages/how-use-arcad-integration-ibm-i-modernization-engine-lifecycle-integration-merlin)
