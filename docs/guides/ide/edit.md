# Editing
  
The (Integrated Development Environment)IDE is based on Eclipse Che/Theia and it has a similar user experiences as Visual Studio (VS) Code.

Here are the features for general source code editing.

* Keyboard shortcuts
* Multiple selections (multi-cursor)
* Column (box) selection
* Save / Auto Save
* Hot Exit
* Find and Replace
* Search across files
* Content assist
* Folding
* File encoding support

For detailed information on editing features, please check out [Visual Studio Code documentation](https://code.visualstudio.com/docs/editor/codebasics)  

For information on using ARCAD tools, see [How to use ARCAD integration with IBM i Modernization Engine for Lifecycle Integration](https://supportcontent.ibm.com/support/pages/how-use-arcad-integration-ibm-i-modernization-engine-lifecycle-integration-merlin)
